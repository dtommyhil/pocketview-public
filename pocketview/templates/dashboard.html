About Pocketview

A personal finance dashboard built with Python, Flask, PostgreSQL, and Plaid Sandbox. Explore the sample spending chart, search transactions, and change the date range. This public demo uses fictional records. The full local app connects through Plaid Link, imports transaction changes with atomic cursor updates, encrypts access tokens, and repairs simulated sign-in failures through Link update mode.
